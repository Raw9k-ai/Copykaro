# Copykaro

Copykaro is a notes website for college students, organised the way the syllabus is: subject, unit, topic. Every topic has one current note. When someone improves it, the new version replaces the old one, and the old ones stay in a history list.

Students don't need an account. They open the site, find their topic and read.

## Why I made it

Our notes live in WhatsApp groups and random Drive folders, with files called `final.pdf`, `final2.pdf` and `latest_final.pdf`. Nobody knows which one is right or if it matches the syllabus. I wanted one place with one current version of every note, checked by someone before students see it.

## What it does

- Browse subjects, units and topics in syllabus order
- Search for a topic by name
- Read notes online or download the PDF
- See older versions of a note and what changed
- Mark topics as done and bookmark them
- Report notes that are wrong or outdated
- Contributors upload notes, and an admin approves or rejects them

There is also a link to [LabPatra](https://raw9k-ai.github.io/LabPatra/), my other project for making lab manual cover pages.

## Built with

React, Vite, Supabase and Cloudflare.

## Things to know

- Progress and bookmarks are saved in your browser, so they don't sync between devices.
- Only upload notes you wrote or have permission to share.
